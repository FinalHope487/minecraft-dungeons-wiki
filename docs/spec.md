# 專案規格

## 最終目標

建立可在公開網頁瀏覽的 Minecraft Dungeons 圖鑑。訪客能從物品圖示查看通用資訊，AI 可依協作規則持續新增條目與分類。作業交付包含 GitHub repo、公開網站、規則檔與一次新增內容的說明。
嚴格使用原版介面，不可拼湊自創圖標或 UI 元件。圖標須可追溯至遊戲原始素材；Minecraft Wiki 用於核對資產名稱、用途和原版畫面。背景設計只可參照參考圖片，只有找不到高畫質素材時才可自行繪製。圖鑑內容需經過驗收才能納入正式圖鑑。圖標類型、命名、來源與路徑見[圖標素材規範](specs/icon-assets.md)。

## 範圍

- 目前收錄 Wiki 武器總表中的 27 種非 Unique 近戰基礎武器（含既有 Sword），保留 Unique 樣本 Diamond Sword，另含遠程 Bow、盔甲 Hunter's Armor、神器 Death Cap Mushroom，以及附魔 Sharpness、Swirling。「全部裝備」為預設總覽，可一次瀏覽近戰、遠程、盔甲與神器。附魔為獨立類別。近戰完整清單與驗收記錄見[近戰武器擴充計畫](plans/2026-11-16-melee-weapons.md)；神器分類與首筆樣本見[神器擴充計畫](plans/2026-11-16-artifact-category.md)。
- 神器使用獨立分類，分類群組設為 `equipment`，因此也會出現在「全部裝備」；神器詳情可列冷卻及已核對的固定效果，不列隨物品強度變動的持續時間。
- 網站使用靜態 JavaScript 模組，預設背包格，預覽埠 4173。桌面採 B 的緊湊資訊層級；720 px 以下採 C 的底部詳情抽屜。兩款版型共用[條目資料契約](specs/content-contract.md)。
- 條目編輯來源為本機 SQLite；GitHub Actions 在 push 後產生靜態 JSON。網站依選取載入條目詳情，離屏圖片延遲載入，不使用外部資料服務。資料庫細節見[SQLite 圖鑑資料庫規範](specs/catalog-storage.md)。
- 站點提供繁體中文與英文。繁中為預設，英文使用 `?lang=en`；語言切換保留同一分類、物品與版型。

## 橫向小方格與下方詳情

列表沿用掉落物介面的緊湊排列。等大的正方形格子從左到右排列，空間不足時換行。物品圖標置中，細框分隔格子，亮白外框標示當前選擇，指標移入或鍵盤聚焦時顯示名稱。桌面在列表正下方更新詳情。

## 背包格與右側詳情

左側採遊戲背包的較大方格，以分類標題和雙線邊框呈現物品。點選時以亮白外框標示當前格子，桌面右側常駐面板同步更新。

## 共用展示規則

- 背包格預設每列三格，提供每列 2–6 格設定，控制放在分類標題旁，只有背包格版型顯示。變更以網址 `columns` 參數保留，預設三格時省略參數；切換分類、物品、語言或版型後設定不變。背包格至少顯示四列，末列補齊。空格使用原版截圖的暗色 X 方格，不計數、不接受選取或焦點。橫向小方格依可用寬度排列，空間不足才換行。
- 720 px 以下，背包格滿版並依可用寬度縮放；固定底部操作列顯示目前選取物品及「查看詳情」按鈕。操作列需保留安全區空間，不能遮擋最後一列。橫向小方格保留標題旁的「查看詳情」按鈕。
- 720 px 以下，兩款版型都可用「查看詳情」開啟底部抽屜。以 Esc 或關閉按鈕關閉後，焦點回到開啟按鈕。

- 詳情沿用遊戲的資訊層級。上方顯示稀有度、名稱與放大圖標，下方呈現固定特性及原文描述。
- 保留物品圖標、已確認的固定效果與原文說明。普通近戰武器依 Wiki 武器總表顯示灰色 `Regular Bullet` 效果；Unique 特性使用橘色 `Unique Bullet` 標記及橘色文字。Diamond Sword 的 `Extra damage` 維持橘色標記；Sword 無普通固有效果，不補造灰色特性。
- 列表和詳情均省略物品等級、隨等級變動的數值，以及特定實例持有的附魔與附魔槽。

## 驗收條件

- 在兩種版型中各自選取 Sword 與 Diamond Sword，確認選中外框、大圖、名稱及原文描述同步更新。
- 在 390、600、720 px 實際瀏覽器寬度檢查每列格數設定、滿版縮放、底部詳情列、抽屜開關及安全區；變更設定後格數與空格補齊正確，重新整理仍保留選擇，末列不被操作列遮住。
- 兩種版型都確認 22 種有普通固有效果的近戰武器顯示灰色 `Regular Bullet`，只有 Diamond Sword 顯示橘色 `Extra damage` 與 `Unique Bullet` 標記，並符合[圖標素材規範](specs/icon-assets.md)。
- 保留條目網址、分類及版型。重新整理可還原選取。無效條目有返首頁連結。
- 遠程只顯示遠程武器，盔甲只顯示盔甲，神器只顯示神器，附魔只顯示附魔。「全部裝備」顯示近戰、遠程、盔甲與神器，選取條目及切換版型後仍保留總覽。
- 以鍵盤可進入分類、條目及窄版詳情抽屜。從 Diamond Sword 可以瀏覽相關附魔 Sharpness，再回到裝備。
- 近戰分類顯示 28 件（27 種 Common / Rare 基礎武器及 Diamond Sword）；預設三欄背包版補齊至 30 格。全部裝備顯示 31 件（28 近戰、1 遠程、1 盔甲、1 神器），預設三欄下無空格；遠程、盔甲與神器各呈現一件加十一個 X 空格。神器分類顯示 Death Cap Mushroom 一件。橫向版可瀏覽全部 31 件。繁中與英文各核對介面、物品名、說明及無效條目，繁中裝備可展開英文原文。

# 網頁設計參考網站

資源	可以用在哪裡
Game UI Database	比較遊戲怎麼排物品格、標示選中狀態，以及在有限空間展示長描述。要抓《Minecraft Dungeons》一代的風格，可先看官方預告解析裡的背包畫面，再用你的遊戲截圖補足細節。
awesome-design-md	借它的文件結構，把截圖觀察寫成自己的 DESIGN.md。例如「選中的物品格有高亮外框」「詳情順序是名稱、稀有度、效果、取得方式」「窄螢幕改用底部抽屜」。後續新增神器或怪物時，AI 有明確規則可沿用。
60fps.design	找「選中回饋」和「面板展開」兩種動效即可。用在點擊物品和開啟手機詳情，連續切換物品時仍能立即讀到內容。
Vercel Web Interface Guidelines	當成原型驗收清單，檢查鍵盤能否選取物品、`Esc` 能否關閉抽屜、關閉後焦點是否回到原物品。原型完成後也可用 Impeccable 審查文字層級與畫面密度。
