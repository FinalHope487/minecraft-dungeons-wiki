# 2026-11-17 · 只公開有來源支持的條目詳情

**決策**：附魔資料保留完整來源稽核內容，但詳情不公開圖鑑自行判讀的 Audience、Evidence confidence、由 Wiki 清單缺項推得的不可用結論或未確認效果。玩家與怪物效果相同時只顯示玩家主效果，怪物側改用相同效果附註；效果不同時保留玩家主效果與怪物差異附註。單側可用時只顯示該側。所有次要 facts、關聯、英文原文與來源收進預設收合的「更多資訊」區塊。

**依據**：使用者要求隱藏推論欄位、保留條目及有來源內容，並指定同效合併、單側效果只呈現可用側。來源資料與可查證效果需保留以供稽核。

**反悔成本**：調整詳情篩選及渲染、資料呈現規格與本地建置驗收；SQLite schema 不變。

**決策者**：使用者決定呈現行為；Codex 依明確來源文字及可用性過濾推論，可信度只供稽核，不作為隱藏有來源效果的門檻。
