# 固定圖鑑外殼並讓欄位各自捲動

- **決策者**：user
- **決策**：固定頁面外殼、頁首、圖鑑主框與詳情欄。背包格和橫向小方格兩種版型都只讓物品列表欄獨立捲動；詳情欄固定，長內容在詳情欄內捲動。窄版詳情抽屜仍在抽屜內捲動。捲軸使用細窄銅色像素樣式與標準 fallback。
- **依據**：使用者看過實際版面後明確指出應捲動其示意中的物品列表欄，詳情頁需固定，並確認詳情過長時可在面板內捲動。
- **實作**：把區域標籤與鍵盤焦點移至物品列表欄；緊湊版型使用上下兩個固定視窗區，列表和詳情各自捲動。選取條目時只在列表欄內定位。
- **回退代價**：恢復工作區為唯一捲動容器，還原舊的焦點區域；不影響條目資料或網址。
