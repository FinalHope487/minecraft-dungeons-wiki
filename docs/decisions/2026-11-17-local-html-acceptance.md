# 2026-11-17 · 以本地建置產物驗收

**決策**：驗收執行 `npm test` 和 `npm run build`，直接檢查 `dist/` 的 HTML、CSS、JavaScript、JSON 與素材；不啟動預覽伺服器或瀏覽器。產物與測試無法證明的實際渲染或互動行為，標記為未驗證。

**依據**：使用者要求改以本地建置 HTML 直接檢查，且不開瀏覽器。執行規則見[專案規則](../project-rules.md#專案目錄與驗證)及[驗收條件](../spec.md#驗收條件)。

**反悔成本**：若恢復瀏覽器驗收，更新專案規則與規格，並重跑需要實際渲染或互動的驗收項目；不影響資料格式或既有存檔。

**決策者**：使用者。
